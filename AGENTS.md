# First group project instructions

This repository is for the Tuesday vibe-coding class. Students are building **Technology 2: AI-Based Traffic-Light Risk Classification System for Older Adults**, a classroom prototype that helps a home care supervisor decide which fictional cases to review first.

## Build in small steps

- Read [README.md](README.md) for the current scope, sample cases, and expected results. Make the smallest change the student can open and try.
- For the first version, use a single `index.html` file that opens directly in a browser. Keep the rules easy to find and explain. Add frameworks, accounts, or external AI services only when the group asks for them.
- Show each result with a text label and a plain-language reason. Use color as a second cue. Use the README’s rule order so an explicit request for prompt review takes priority and missing information never defaults to green.
- Use fictional cases throughout. Keep the original Word submission intact and local. Keep project files, drafts, and generated assets within this group folder.
- Treat results as review priorities for a human supervisor. Keep the classroom rules clearly labeled as examples. Leave rule changes and decisions about introducing AI to the group.

## Check the result with students

- Open the page as a student would. Try every sample case in the README and check both the label and the explanation. After a change, repeat the affected cases.
- Tell students what to open, click, and expect. If they report a problem, ask for the exact message or the actions that caused it when those details are missing. Explain the likely cause in plain language and make one focused change.
